# Phase 2 Back Navigation QA

- Beginner journey step 1: back returns to My Abacus World.
- Beginner journey steps 2–5: back returns to the previous learning step.
- Beginner journey completion: back returns to the final challenge step.
- Any child page with a `.topbar` but no existing `.icon-btn` receives a safe fallback back button.
- Existing page-specific back buttons are not duplicated.
- Onboarding and the root World screen are not given a fallback back button.
